中文版

1. 概述

X History（以下简称"本插件"）是一款 Chrome 浏览器扩展，用于自动记录您在 X（原 Twitter）首页时间线上浏览过的推文，方便您日后回顾。本插件由个人开发者独立开发，不隶属于 X Corp.。

2. 收集的数据

本插件仅在您浏览 x.com 时收集以下信息：

  • 推文 ID、发布时间
  • 推文文本内容
  • 发推账号的用户名和显示名称
  • 文章预览的标题、摘要、封面图片 URL（如有）
  • 您首次及最近查看该推文的时间戳

3. 数据存储与使用

所有数据均仅存储在您本地浏览器中（通过 Chrome 扩展的 chrome.storage.local API）。本插件：

  • 不会将任何数据上传至服务器
  • 不会将数据发送给任何第三方
  • 不会用于广告、追踪或任何商业目的
  • 不会用于用户画像或个人信用评估

4. 数据删除

您可以随时通过以下方式删除全部数据：

  • 卸载本插件（浏览器将自动清除所有本地存储数据）
  • 在 Chrome 扩展设置中清除该扩展的存储数据

5. 权限说明

  • storage：用于将浏览历史保存在本地浏览器中。
  • host_permissions (x.com)：用于在 X 页面中注入历史记录面板并读取时间线推文内容。

6. 联系方式

如有任何隐私相关问题，请通过 GitHub Issues 联系开发者：https://github.com/320km-h/111

English Version

1. Overview

X History is a Chrome browser extension that automatically records tweets you have viewed on X's (formerly Twitter) home timeline for later review. It is independently developed and is not affiliated with X Corp.

2. Data Collected

The extension collects the following information only while you browse x.com:

  • Tweet ID and post timestamp
  • Tweet text content
  • Author username and display name
  • Article preview title, summary, and cover image URL (if applicable)
  • Timestamps of when you first and most recently viewed the tweet

3. Data Storage and Use

All data is stored locally in your browser only via Chrome's chrome.storage.local API. This extension:

  • Does NOT upload any data to remote servers
  • Does NOT share data with any third parties
  • Does NOT use data for advertising, tracking, or any commercial purpose
  • Does NOT use data for profiling or credit assessment

4. Data Deletion

You can delete all stored data at any time by:

  • Uninstalling the extension (Chrome will automatically clear all local storage)
  • Clearing the extension's storage data via Chrome extension settings

5. Permissions Justification

  • storage: Used to save your browsing history locally in the browser.
  • host_permissions (x.com): Used to inject the history panel into X pages and read timeline tweet content.

6. Contact

For any privacy-related questions, please contact via GitHub Issues: https://github.com/320km-h/111
